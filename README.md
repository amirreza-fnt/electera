# Liquid Glass & Harmony — static demos

Collection of standalone HTML/CSS/JS demos: glass navigation, iOS 26 liquid glass, harmony home, audio player, and background blend experiments.

## GitHub Pages

After deploy, open:

- **Home:** `https://<your-username>.github.io/<repo-name>/`
- **Harmony home:** `…/harmony-home.html`
- **iOS 26 buttons:** `…/ios26-buttons.html`

Static site — no build step. Serve from repository root (`/`).
