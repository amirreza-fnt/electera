Liquid Glass Buttons

lg-btn clear · lg-btn--frosted frosted

Sizes

sm · md · lg · xl — every dimension scales from font-size

Variants

clear · frosted · tinted (--lg-tint: R G B)

Shapes

circle · pill · icon-only (label stays for screen readers)

States

default · hover · active · focus · selected · disabled · loading

Interactive

Toggle buttons keep aria-pressed; the first one simulates a 1.5s loading action.

Usage

<link rel="stylesheet" href="css/liquid-glass-button.css?v=20260927222405">
<script src="js/liquid-glass-button.js?v=20260927222405" defer></script>

<button class="lg-btn lg-btn--frosted lg-btn--lg" type="button">
  <span class="lg-btn__icon"><svg viewBox="0 0 24 24">…</svg></span>
  <span class="lg-btn__label">Home</span>
</button>
const btn = LiquidGlassButton.create({
  label: "Search",
  icon: "search",        // home · search · heart · settings · play · bell · plus · user · camera · check
  variant: "frosted",    // clear · frosted · tinted
  size: "lg",            // sm · md · lg · xl
  shape: "circle",       // circle · pill · icon
  toggle: true,
  onClick: (e, el) => console.log(el.getAttribute("aria-pressed")),
});
document.body.append(btn);
